Meta Description: Pengertian dan Cara Menggunakannya

Meta description adalah informasi singkat yang ditempatkan pada bagian head sebuah halaman HTML. Deskripsi ini memberikan gambaran mengenai isi halaman kepada mesin pencari dan pengguna.

Catatan: meta description sebaiknya menggambarkan isi halaman secara akurat dan tidak dibuat hanya untuk memasukkan kata kunci.

1. Apa Itu Meta Description?

Meta description menggunakan elemen HTML meta dengan atribut name="description". Isinya berupa ringkasan singkat mengenai informasi yang tersedia pada sebuah halaman.

2. Mengapa Meta Description Penting?

Deskripsi yang jelas dapat membantu pengguna memahami isi halaman sebelum mereka membukanya dari hasil pencarian. Namun, meta description bukan jaminan bahwa teks tersebut akan selalu ditampilkan oleh mesin pencari.

3. Cara Membuat Meta Description

Buat deskripsi yang sesuai dengan isi halaman. Gunakan bahasa yang natural dan jelaskan informasi utama yang akan ditemukan pembaca.

Hindari membuat deskripsi yang sama untuk semua halaman. Setiap halaman sebaiknya memiliki deskripsi yang sesuai dengan topiknya.

4. Hubungan dengan Struktur SEO

Meta description hanyalah salah satu bagian dari struktur sebuah halaman. SEO juga mencakup judul halaman, heading, internal link, struktur URL, sitemap, dan kualitas konten.

Untuk mempelajari dasar SEO secara lebih lengkap, baca Dasar SEO untuk Pemula.

5. Kesimpulan

Meta description merupakan ringkasan halaman yang membantu memberikan konteks mengenai isi sebuah halaman. Deskripsi yang baik harus relevan dengan konten dan ditulis secara natural.
